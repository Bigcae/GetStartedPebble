# Installation

Follow these steps to install Pebble on your system.

## Installation Methods

### Option 1: Using npm (Recommended)

Install Pebble globally using npm:

```bash
npm install -g pebble
```

### Option 2: Using yarn

Alternatively, you can use yarn:

```bash
yarn global add pebble
```

### Option 3: From Source

For advanced users who want to build from source:

```bash
git clone https://github.com/pebble/pebble.git
cd pebble
npm install
npm run build
```

## Verify Installation

After installation, verify that Pebble is installed correctly:

```bash
pebble --version
```

You should see the version number displayed.

## Troubleshooting

If you encounter any issues during installation:

* Ensure you have the latest version of npm/yarn
* Check that you have proper permissions (you may need sudo on Linux/macOS)
* Verify your internet connection is stable

## Next Steps

Now that Pebble is installed, proceed to the [Quick Start Guide](../quick-start/README.md) to begin using it.
