# Quick Start Guide

Get up and running with Pebble in minutes! This guide provides a hands-on walkthrough to help you start using Pebble immediately.

## Overview

This quick start guide will walk you through:

1. **Setup** - Initial configuration and project setup
2. **Basic Usage** - Common commands and workflows
3. **Examples** - Practical examples to get you started

## What You'll Build

By the end of this guide, you'll have:

* A configured Pebble project
* Understanding of basic Pebble commands
* Working examples you can modify and extend
